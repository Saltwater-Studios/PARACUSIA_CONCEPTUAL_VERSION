# PARACUSIA CONCEPTUAL BUILD
PARACUSIA is a slow-paced horror-comedy game about mining, primarily inspired by Voices of the Void and Cavern Crusher. Against your will, you must descend into its gaping maw. 

As this is a conceptual build, not all features are in the game yet, and this project far from complete.

Only one person is developing all of this (whilst I [the one developing it] am still learning many, many things), so, expect progress to be relatively slow.

****THIS IS ONLY A PLACE TO TRACK THE UPDATES MADE TO THE GAME.****
****THIS GAME WILL NOT GO OPEN-SOURCE FOR A LONG, LONG TIME.****
(If at all)

# WHAT TYPE OF GAME IS THIS?

PARACUSIA is best described as a mix of different genres. While it is primarily a psychological horror, comedy, and adventure game, the game will also fall under different genres.

You can describe PARACUSIA as any of these genres and it will be technically correct:

- ***Horror***
- Psychological horror
- Body horror
- Monster horror
- Ambient horror
- Survival horror
- "Quiet" horror

- ***Comedy***
- Slapstick comedy
- Surrealist comedy
- Quirky comedy
- Dry comedy

- ***Thriller***
- Psychological thriller

- ***Survival***

- ***Adventure***

- ***Fantasy***

- ***Simulation***
- Life-sim
- Job-sim

- ***Misc/descriptive terms***
- Sandbox
- Open-world
- Whimsical
- Silly
- Slow-paced
- Semi-experimentalist
- Vent game

(Have fun describing this game to someone as a "whimsical quirky-comedy fantasy game" because you'd technically not be wrong. This was also supposed to be more "spaced-out" but GitHub won't allow me for some reason to do that.)
  
# CURRENT FEATURES:

- Basic movement
- Sleeping system/sleep bar
- Different handheld light sources (including the ability to switch between them)
- In-game computer/PC system where you can buy stuff
  
# FEATURES ACTIVELY BEING WORKED ON:

- Terrain (This is mostly done; only minor touch-ups are needed)
- Music
- HUD/GUI

# FEATURES THAT WILL BE WORKED ON MUCH LATER FROM NOW, BUT WILL STILL BE IN THE GAME BY THE RELEASE OF THE FIRST BUILD:

- A simple, continuous mining system with a few interesting ores
- Scary events
- A bike that allows you to move quicker

# FEATURES WHICH MAY OR MAY NOT BE COMPLETE WHEN THE FIRST BUILD RELEASES:

- Two different biomes (in total)
- Hunger
- A (slightly) more advanced movement system
